# STM32 智能小车控制系统

基于 **STM32F103C8Tx** 的智能小车控制固件。项目采用 STM32CubeMX 管理基础时钟和外设配置，使用 CMake 与 Arm GNU Toolchain 构建。应用层按功能拆分为独立模块，主循环以 `HAL_GetTick()` 时间片和状态机调度为主；OLED 的 I2C 发送、串口文本输出等仍使用阻塞式 HAL 接口，部分底层时序使用短时忙等待，并非全程非阻塞。

## 项目能力

| 类别 | 已实现能力 |
| --- | --- |
| 手动控制 | 通过蓝牙串口控制前进、后退、转向、停车与速度 |
| 循迹运输 | 循迹、到点确认、称重装载、舵机卸货、返航与超时保护 |
| UWB 跟随 | 根据 UWB 距离、角度和信号强度执行限速跟随 |
| 安全控制 | 超声波避障、急停、运动指令超时与健康监测 |
| 反馈交互 | OLED 状态显示、蜂鸣器和 RGB 状态提示 |

以上描述当前源码中的功能，不代表所有硬件组合均已通过实机验证。

## 硬件与外设

- MCU：STM32F103C8Tx，Cortex-M3
- 系统时钟：外部 8 MHz 晶振，PLL 后 72 MHz
- 电机：TIM2 双通道 PWM
- 卸货舵机：TIM1 CH1 PWM
- 蓝牙/调试串口：USART1
- UWB 数据串口：USART2
- OLED：I2C1（SSD1306，默认地址 `0x3C`）
- 传感器：循迹、编码器、HC-SR04 超声波、HX711 称重模块
- 调试与烧录：SWD

基础外设和时钟配置见 [`auto_car.ioc`](auto_car.ioc)；运行时还会由应用模块手动初始化部分资源，例如 `encoder.c` 中的 TIM3 编码器与右编码器外部中断、HX711、WS2812 和按键 GPIO。修改接线或重新生成工程时，需要同时核对 CubeMX 配置、生成代码和模块初始化代码。详细配置来源及接线见 [硬件接线说明](docs/HARDWARE.md)。

## 运行模式

| 模式 | 说明 |
| --- | --- |
| 自动运输 | 默认模式；执行等待装载、循迹运输、卸货与返航流程 |
| 蓝牙控制 | 接收手动运动、模式、卸货和状态查询指令 |
| UWB 跟随 | 使用 UWB 测距与角度数据跟随目标标签 |

PC14 按键按“自动运输 → 蓝牙控制 → UWB 跟随 → 自动运输”的顺序循环切换。PC15 用于手动开关卸货舵机；打开时会停车并进入手动运动模式，再次关闭不会自动恢复此前的运输或跟随任务，需要通过 PC14 重新选择。两个按键在代码中均配置为上拉输入、低电平有效。

## 蓝牙指令

USART1 使用 **115200 bit/s、8 数据位、无校验、1 停止位（8N1）、无硬件流控**。蓝牙模块的串口侧必须与此一致。接收格式为单字符 ASCII，字母指令大小写均可，回车和换行会被忽略。

先通过 PC14 选择蓝牙控制，再发送运动或模式切换指令；`X`（急停）和 `H`（状态查询）不受此模式限制。

| 指令 | 功能 |
| --- | --- |
| `F` / `B` | 前进 / 后退 |
| `L` / `R` | 左转 / 右转 |
| `S` | 停车并切回手动运动模式；在蓝牙控制模式下也可解除急停锁定 |
| `+` / `-` | 增加 / 降低速度 |
| `A` | 自动避障模式 |
| `T` | 循迹模式 |
| `U` | UWB 跟随模式 |
| `O` / `C` | 打开 / 关闭卸货舵机；仅在蓝牙控制且处于手动运动或急停状态时允许 |
| `X` | 急停 |
| `H` | 输出任务耗时、传感器和通信状态 |

手动运动指令有效期为 **800 ms**（`bluetooth.c` 的 `BLUETOOTH_MANUAL_MOTION_TTL_MS`）。持续行驶时，应以小于 800 ms 的间隔重复发送当前方向指令，例如每 200 ms 发送一次 `F`；松开控制键时发送 `S`。若没有新的有效运动指令续期，运动任务会在到期后的下一次调度中停车。`H` 查询不会续期，单次发送 `F` 后短暂行驶再停车是当前设计行为。实际停车响应还受主循环调度和阻塞通信耗时影响。

## 工程结构

```text
Core/Inc/            应用模块对外接口与配置
Core/Src/            业务逻辑、驱动封装和状态机
Drivers/             STM32 HAL 与 CMSIS 依赖
cmake/               CMake 工具链和 CubeMX 构建配置
auto_car.ioc         STM32CubeMX 工程配置
CMakeLists.txt       构建入口
```

关键参数集中在以下文件中：

- `Core/Inc/app_config.h`：调试开关、UWB 协议和跟随参数。
- `Core/Inc/transport_config.h`：运输、避障、装卸与返航阈值。
- `Core/Inc/stm32f1xx_hal_conf.h`：STM32 HAL 组件配置。

## 构建

### 环境要求

- CMake 3.22 或更高版本
- Ninja
- Arm GNU Toolchain，且 `arm-none-eabi-gcc` 已加入 `PATH`

### 编译

在仓库根目录执行：

```powershell
cmake --preset Debug
cmake --build --preset Debug
```

生成的 ELF 文件位于 `build/Debug/`，构建产物不会被 Git 跟踪。

### 烧录

安装 STM32CubeProgrammer，并将 `STM32_Programmer_CLI` 加入 `PATH`，然后重新配置工程以生成 `flash` 目标：

```powershell
cmake --preset Debug
cmake --build build/Debug --target flash
```

也可以使用 STM32CubeIDE 或 STM32CubeProgrammer，通过 SWD 手动烧录 ELF 文件。

## 使用与安全

本仓库只提供源代码，不包含预编译固件。电机、舵机和传感器的供电、地线、电平转换与标定会直接影响运行结果。

首次上电时应抬空驱动轮，使用独立电源为电机和舵机供电，并与 STM32 共地。请在受控场地完成循迹、距离、重量和 UWB 参数标定后再进行载重运行。
