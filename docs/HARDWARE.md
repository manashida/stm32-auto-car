# 硬件接线说明

本文档与当前固件源码对应。修改模块型号、接线或 `auto_car.ioc` 后，应同步更新本文档并重新完成基础功能验证。

## 配置来源

`auto_car.ioc` 记录基础时钟、TIM1/TIM2、I2C1、USART1/USART2 和部分 GPIO 配置。当前运行配置还包括应用模块中的手动初始化，不能仅凭 `.ioc` 还原全部硬件设置：

| 配置位置 | 运行时配置 |
| --- | --- |
| `Core/Src/encoder.c` | TIM3 左编码器、PB12 右编码器 EXTI、PB13 输入及中断优先级 |
| `Core/Src/hx711.c` | PB14/PB15 称重接口 GPIO |
| `Core/Src/ws2812.c` | PA12 灯带数据 GPIO 与发送时序 |
| `Core/Src/app_mode_task.c` | PC14/PC15 按键上拉输入与消抖 |
| `Core/Src/buzzer.c` | PA11 蜂鸣器输出及低电平有效逻辑 |

重新生成 CubeMX 工程后，应对照上述模块及 `Core/Src` 下的外设、中断代码复核。源码中的配置记录不等同于实机接线验证结果。

## 串口与控制约定

USART1（蓝牙）和 USART2（UWB）在 `Core/Src/usart.c` 中均配置为 **115200 bit/s、8N1、无硬件流控**。应核对模块当前串口设置，不应假定其出厂波特率与固件一致。

蓝牙使用单字符 ASCII 指令，运动控制需先通过 PC14 切换到蓝牙控制模式。方向指令有效期为 800 ms，持续行驶时需周期性重发，松开控制键时发送 `S`；完整指令与急停说明见 [README](../README.md)。USART2 接收 UWB 二进制帧，其字段和校验必须匹配 `uwb_follow.c`；协议开关和目标标签过滤配置见 `Core/Inc/app_config.h`。

## 电源与电气要求

- STM32、TB6612、传感器、蓝牙、UWB 和舵机电源必须共地。
- 电机和舵机应使用独立的、满足峰值电流要求的电源；不要由 STM32 开发板的 3.3 V 输出直接供电。
- TB6612 的 `STBY` 必须拉高才能驱动电机。根据所用驱动板规格选择合适逻辑电平。
- HC-SR04 的 `ECHO` 通常为 5 V，接入 PA5 前必须降压至 3.3 V。
- 使用 5 V 供电的 WS2812 时，3.3 V 数据高电平可能不满足裕量，建议增加 3.3 V 至 5 V 电平转换器，并在灯带电源端增加去耦电容。
- 蓝牙/UWB 模块的串口电平和供电要求因模块而异。若 RX 引脚不兼容 3.3 V，应增加电平转换。
- 舵机、电机供电线上建议就近增加储能电容，并避免与敏感模拟信号共用细长回流路径。

## 上电与首检顺序

1. 不接电机和舵机电源时，先通过 SWD 烧录固件并确认 3.3 V 电源正常。
2. 接入 OLED、蓝牙和 UWB，检查串口数据和状态显示是否正常。
3. 抬空驱动轮后接入电机电源，先验证左右电机方向；方向相反时调整 `Core/Src/motor.c` 中的 `LEFT_MOTOR_INVERT` 或 `RIGHT_MOTOR_INVERT`。
4. 分别测试超声波距离、循迹信号、编码器计数、HX711 零点与舵机开闭范围。
5. 完成称重比例、循迹速度、UWB 跟随距离和运输状态机阈值标定后，再进行地面与载重测试。

## 需要标定的参数

| 参数 | 文件 | 用途 |
| --- | --- | --- |
| HX711 比例系数 | `Core/Inc/hx711.h` | 将原始 ADC 值换算为重量 |

## 注意事项

- 本文档描述的是当前固件接口，不替代模块厂商数据手册。
- 修改 `auto_car.ioc` 后，应重新检查 CubeMX 生成代码与 `Core/Src` 中手动初始化的编码器、HX711、WS2812 和按键配置是否冲突。
- 请在受控环境内调试，并始终保留可快速断开电机/舵机电源的方式。
